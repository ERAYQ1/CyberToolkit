# CyberToolkit Executable Build Instructions

The application uses standard Python 3.10+ along with PySide6, scapy, and psutil.
To convert this project into a standalone executable (e.g. `CyberToolkit.exe`), follow these steps using `pyinstaller`.

### 1. Install PyInstaller
First, ensure you have PyInstaller installed in your environment:
```cmd
pip install pyinstaller
```

### 2. Build the Executable
Open a terminal in the project root directory (where `main.py` is located) and run the following command. The `--windowed` flag ensures that a background command line window does not pop up.

```cmd
pyinstaller --name "CyberToolkit" --windowed --noconfirm --icon=NONE main.py
```
*(You can optionally provide an icon file by using `--icon=assets/icon.ico` if you add one later)*

### 3. Retrieve your Executable
Once the build process completes, your `.exe` file will be located inside the generated `dist/` directory:
```
dist/CyberToolkit/CyberToolkit.exe
```
or `dist/CyberToolkit.exe` if you use the `--onefile` flag. 

**Note on Admin Privileges:**
Some capabilities of this toolkit, especially Scapy ARP scans and low-level port monitoring, might require running the application with **Administrator privileges** to function fully on Windows. If the network features do not populate properly, please right-click the `.exe` and select "Run as Administrator".
